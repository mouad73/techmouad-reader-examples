# محضر منشورات فيسبوك بسيط

لإعداد اتصال اختياري بصفحة فيسبوك وتحديد Page ID وApp ID وApp Secret وPage access token، اتبع [دليل إعداد Meta](META-SETUP.ar.md). هذه إرشادات لمرحلة نشر مستقبلية؛ السكربت المرفق لا يقرأ تلك المفاتيح ولا ينشر إلى فيسبوك.

مثال مستقل لإنشاء حزمة محلية: صورة PNG عربية 1080×1350، نص، مصادر، معاينة HTML وقائمة مراجعة. لا يتصل بفيسبوك أو بأي API للذكاء الاصطناعي. لا يحتاج توكنات. النشر يدوي بعد المراجعة.

## التشغيل

من هذا المجلد، مع Python 3.11+:

```sh
python -m pip install -r requirements.txt
python build.py --input story.example.json --out output/demo
```

افتح `output/demo/preview.html`. هذه بيانات ومصادر تجريبية؛ لا تنشرها كخبر. يحتاج الرسم خطاً عربياً وPillow مع دعم libraqm. يمكن تحديد الخط:

```sh
python build.py --input story.example.json --out output/demo-font --font /path/to/arabic-font.ttf
```

## مادة حقيقية

1. انسخ `prompts/01-research.ar.txt` إلى مساعدك، وحدد موضوعك. افتح المصادر الأصلية بنفسك.
2. استخدم `02-write.ar.txt` مع البحث الذي راجعته، واحفظ JSON الناتج باسم `story.json`.
3. راجع العنوان والنص والمصادر. اجعل `reviewed` يساوي `true` بعد المراجعة فقط، مع `demo=false`.
4. شغّل `python build.py --input story.json --out output/my-post`.
5. افتح المعاينة وانشر الصورة والنص وروابط المصادر يدوياً إذا كانت مناسبة.

التحقق من اختلاف نطاقين لا يثبت استقلالهما أو صحة الخبر. لا يعيد السكربت الكتابة فوق مجلد موجود. `state.sqlite3` سجل للحزمة المحلية وليس إيصال نشر أو ضماناً لمنع نشرها مرتين. أمر بناء واحد ينشئ حزمة واحدة؛ لا توجد مهمة يومية سحابية مدمجة.
