# مثال قائمة تنقل عربية مستقلة

افتح `index.html` في متصفح، أو من هذا المجلد شغّل `python -m http.server 8080 --bind 127.0.0.1` وافتح http://127.0.0.1:8080/.

ملفات التشغيل: `index.html` و`styles.css` و`navigation.js`. لا توجد مكتبات أو خدمات خارجية أو مفاتيح. المثال يعرض فتح قائمة الهاتف وإغلاقها، `aria-expanded`، قفل تمرير الصفحة، وتغير حالة الرأس عند التمرير. لا يعيد بناء تطبيق كامل.

للنشر الثابت، ارفع الملفات الثلاثة إلى مجلد موقع منفصل في الاستضافة المناسبة. هذا استضافة لملفات HTML/CSS/JS وليس تشغيل أداة REA على الخادم. لا ترفع مشروعك الخاص أو ملفاته السرية مع المثال.

## إعادة تحليل المثال باستخدام REA

فتح صفحة المثال لا يتطلب Node أو REA. أما تحليل ملفاتها بأداة REA فهو اختبار منفصل؛ لا يعيد إنتاج أرقام دراسة الحالة الأصلية التي استخدمت مدخلاً مختلفاً.

الإصدار المختبر هو `rea-agents@6.8.0`. يتطلب وفق بيانات الحزمة Node **22.23.4+ ضمن 22.x، أو 24.22.1+ ضمن 24.x، أو 26.12.1+**. تحقّق باستخدام `node --version` و`npm --version`؛ Node 24.12.0 مثلاً أقدم من المتطلب. إصدار REA المثبت مهم؛ لا تفترض أن `@latest` سيطابق نتائج هذا الدليل.

من **جذر المستودع** الذي يحتوي مجلد `rea-navigation-demo`، أنشئ مجلد أدوات شقيقاً ثم نفّذ:

```sh
mkdir rea-reader-check
cd rea-reader-check
npx --yes rea-agents@6.8.0 analyze-javascript-application ../rea-navigation-demo --json --full-output --max-heap-mb 256
```

تجري عملية الحصول على الحزمة خارج مجلد المدخل. على Linux يلزم `ps` من procps متاحاً في PATH. هذا المسار الطرفي لا يحتاج ربط وكيل أو تغيير إعدادات MCP أو محرك تحليل أصلي. راجع [دليل REA الرسمي](https://github.com/morluto/rea/blob/main/docs/ci-analysis.md).

أُعيد اختبار أمر npx المثبت بالإصدار المحدد على Linux بحساب غير مميز وذاكرة npm مؤقتة جديدة، بعد تنزيل النسخة العامة. نجح برمز خروج صفر، و`ok=true`، وملف JavaScript واحد محلل، دون أخطاء parsing. هذه نتيجة المثال الصغير فقط؛ راجع القيود في التقرير ولا تستخدمها كبرهان على فهم كامل.

يمكن ضبط ذاكرة العملية الأم قبل الأمر إذا لزم. في Bash: `export NODE_OPTIONS=--max-old-space-size=768`. وفي PowerShell: `$env:NODE_OPTIONS="--max-old-space-size=768"`. هذا حد تشغيل اختياري للتجربة وليس متطلب استضافة الملفات الثلاثة.

احتفظ بـstdout وstderr ورمز الخروج كل على حدة. رمز الخروج صفر لا يثبت اكتمال الفهم: افحص `ok` وإحصاءات parsing والقيود وunknowns. لم تُنفذ شيفرة الصفحة أثناء التحليل الساكن. لا تعالج فشل التثبيت أو غياب `cmd.exe` في Windows على أنه نجاح للأداة؛ أصلح بيئة الطرفية أو استخدم بيئة مدعومة. اختبارنا على Windows استدعى CLI مباشرة باستخدام Node 24.22.2 لأن `cmd.exe` كان مفقوداً في بيئة الاختبار؛ لم ينجح أمر إعداد npx القياسي على تلك البيئة.

يمكن أيضاً استخدام `prompt.ar.txt` مع وكيلك بعد إعداد REA لديه بالطريقة الرسمية. هذا مسار آخر، ولم نغيّر إعدادات الوكيل أثناء اختبار النسخة القابلة للتنزيل.
