# TechMouad reader examples

Small standalone examples for the tutorials at https://techmouad.com.

| Folder | What readers can run |
|---|---|
| `facebook-content-starter` | Build an Arabic PNG package, then optionally publish its reviewed image and caption to your own Facebook Page |
| `faceless-video-starter` | Turn a short Arabic scene list into subtitles and a vertical MP4 with FFmpeg |
| `make-blueprints` | Import WordPress → Telegram, RSS → Telegram, or Sheets → WordPress draft templates |
| `rea-navigation-demo` | Open and deploy an independent HTML/CSS/JS mobile-navigation example |

These examples use sample data. They do not include private projects, account connections, tokens or posting histories. Review generated text and media before using them. The Facebook publisher makes a real API call only with explicit publication options and your own Page token; the video starter does not upload videos. Neither starter makes AI API calls. Copy the editable prompts into an assistant of your choice, verify its sources, and save the reviewed result in the documented JSON format.

Each folder has its own instructions. Python 3.11+ is recommended. All new example code is MIT licensed. Third-party software has its own licenses.
