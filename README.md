# TechMouad reader examples

Small standalone examples for the tutorials at https://techmouad.com.

| Folder | What readers can run |
|---|---|
| `facebook-content-starter` | Build an Arabic PNG package, then optionally publish its reviewed image and caption to your own Facebook Page |
| `faceless-video-starter` | Turn a short Arabic scene list into subtitles and a vertical MP4 with FFmpeg |
| `make-blueprints` | Import WordPress → Telegram, RSS → Telegram, or Sheets → WordPress draft templates |
| `rea-navigation-demo` | Open and deploy an independent HTML/CSS/JS mobile-navigation example |
| `kie-video-starter` | Preview a Kling video request locally, explicitly submit one paid task, poll and download its result |
| `hostinger-wordpress-checklist` | Follow a documented launch checklist and run a read-only public-page check |
| `n8n-hosting-lab` | Try an isolated Docker lab and import an inactive manual-only sample workflow |

These examples use sample data. They do not include private projects, account connections, tokens or posting histories. Review generated text and media before using them. The Facebook publisher makes a real API call only with explicit publication options and your own Page token. The faceless-video starter renders locally. The separate Kie video starter makes a paid AI API call only with explicit creation options and your own key; its default mode is offline preview. Neither video starter uploads to social platforms. Copy the editable prompts into an assistant of your choice, verify its sources, and save the reviewed result in the documented format.

Each folder has its own instructions. Python 3.11+ is recommended. All new example code is MIT licensed. Third-party software has its own licenses.
