# توليد فيديو قصير عبر Kie.ai

هذا المثال يرسل طلب نص إلى فيديو إلى `kling/v3-turbo-text-to-video` ثم يفحص نفس المهمة وينزل نتيجتها. لا يرفع أي فيديو إلى الشبكات الاجتماعية. تحتاج Python 3.11 أو أحدث وحساب Kie.ai ومفتاحك الخاص. لا توجد مكتبات Python إضافية.

افتح PowerShell داخل هذا المجلد:

```powershell
Copy-Item .env.example .env
notepad .env
python --version
python video.py
```

ضع مفتاحك في `.env` بدلاً من القيمة التجريبية، واحفظه محلياً. لا ترسل المفتاح إلى GitHub أو الدردشة. ملف `prompt.txt` هو البرومبت القابل للتعديل. الأمر الأخير معاينة محلية بلا شبكة أو خصم.

الإعدادات ثابتة: 3 ثوان، عمودي 9:16، ودقة 720p. في 1 نوفمبر 2026 عرضت صفحة النموذج 18 رصيداً للثانية، أي 54 رصيداً للتجربة ونحو 0.27 دولار بالسعر الاسمي المعروض. راجع السعر الحالي قبل الإرسال. `--max-credits` تأكيد للتقدير المحلي فقط، وليس سقف فوترة يفرضه خادم Kie.ai. احذف التجربة أو عدّلها قبل التشغيل إذا تغير السعر. هذا النموذج يخرج مساراً صوتياً دائماً؛ لا توجد معلمة لتعطيله.

```powershell
python video.py --create --max-credits 54
python video.py --poll
```

كرّر `--poll` بعد 15–30 ثانية إذا ظهرت waiting أو queuing أو generating. استمر مع نفس المهمة؛ لا تعِد أمر الإنشاء. بعد success:

```powershell
python video.py --download
Start-Process .\output\video.mp4
```

توجد حالة المهمة ورقمها والتكلفة التي يعيدها المزود في `output/state.json`. احتفظ بهذا الملف؛ حذفه يفقد حماية هذه النسخة من التكرار. إذا انقطع إنشاء المهمة ولم يُحفظ رقمها، افحص سجل حسابك أولاً؛ يرفض البرنامج إعادة الإرسال تلقائياً. لا يضمن هذا الملف منع التكرار بين أجهزة أو مجلدات مختلفة.

إذا فشل التنزيل، أعد `--download` لنفس المهمة الناجحة. إذا كان الملف المحلي موجوداً افحصه أولاً؛ لا يستبدله البرنامج. لا تتضمن رسائل الأخطاء المفتاح أو رد API الخام. البرنامج لا يتحقق من صحة المحتوى المرئي أو حقوق استعماله، ولا ينفذ webhook أو جدولة أو إعادة محاولة تلقائية لطلبات الإنشاء.

للتأكد من الأبعاد والمدة عند وجود FFmpeg:

```powershell
ffprobe -v error -show_entries format=duration:stream=codec_type,width,height -of json .\output\video.mp4
```
